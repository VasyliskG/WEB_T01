# Симуляція перевірки політики CORS

## 1. Preflight-запит

Попередній запит браузера методом `OPTIONS` до ресурсу `https://httpbin.org/post` виконано командою:

```bash
curl -i -X OPTIONS "https://httpbin.org/post" \
	-H "Origin: https://my-college-app.edu" \
	-H "Access-Control-Request-Method: POST" \
	-H "Access-Control-Request-Headers: Content-Type, Authorization"
```

Заголовок `Origin` імітує запит із вебзастосунку `https://my-college-app.edu`. Заголовки `Access-Control-Request-Method` та `Access-Control-Request-Headers` повідомляють серверу, який метод і які заголовки буде використано в основному запиті.

## 2. Результат

Сервер повернув відповідь:

```text
HTTP/2 200
content-type: text/html; charset=utf-8
content-length: 0
allow: POST, OPTIONS
access-control-allow-origin: https://my-college-app.edu
access-control-allow-credentials: true
access-control-allow-methods: GET, POST, PUT, DELETE, PATCH, OPTIONS
access-control-max-age: 3600
access-control-allow-headers: Content-Type, Authorization
```

Статус `200 OK` означає, що сервер успішно обробив preflight-запит. Тіло відповіді порожнє, що підтверджується значенням `content-length: 0`.

## 3. Аналіз CORS-заголовків

| Заголовок | Значення | Аналіз |
|---|---|---|
| `Access-Control-Allow-Origin` | `https://my-college-app.edu` | Сервер дозволяє запити саме з цього джерела. |
| `Access-Control-Allow-Methods` | `GET, POST, PUT, DELETE, PATCH, OPTIONS` | Метод `POST`, вказаний у preflight-запиті, дозволений. |
| `Access-Control-Allow-Headers` | `Content-Type, Authorization` | Обидва запитані заголовки дозволені в основному запиті. |
| `Access-Control-Allow-Credentials` | `true` | Сервер дозволяє передавання облікових даних, наприклад cookies або авторизаційних даних. |
| `Access-Control-Max-Age` | `3600` | Результат preflight-перевірки можна кешувати протягом 3600 секунд. |

Заголовок `allow: POST, OPTIONS` додатково підтверджує, що ресурс підтримує методи `POST` та `OPTIONS`.

## Висновок

Preflight-перевірка CORS завершилася успішно зі статусом `200 OK`. Сервер дозволив джерело `https://my-college-app.edu`, метод `POST` і заголовки `Content-Type` та `Authorization`. Отже, браузер може виконати основний кроссайтовий `POST`-запит до `https://httpbin.org/post`.
