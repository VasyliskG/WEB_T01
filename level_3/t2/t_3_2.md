# Дослідження життєвого циклу Cookie через Cookie Jar

## 1. Збереження cookies

Для отримання cookies та їх збереження у файл `cookies.txt` виконано:

```bash
curl -L -c cookies.txt "https://httpbin.org/cookies/set?user_role=student&session_key=lab1_token"
```

Прапорець `-c cookies.txt` записує cookies, отримані від сервера, у файл Cookie Jar. Прапорець `-L` дозволяє `curl` перейти за перенаправленням, яке повертає endpoint встановлення cookies.

Відповідь сервера:

```json
{
	"cookies": {
		"session_key": "lab1_token",
		"user_role": "student"
	}
}
```

## 2. Аналіз файлу Cookie Jar

Вміст `cookies.txt`:

```text
# Netscape HTTP Cookie File
# https://curl.se/docs/http-cookies.html
# This file was generated by libcurl! Edit at your own risk.

httpbin.org     FALSE   /       FALSE   0       session_key     lab1_token
httpbin.org     FALSE   /       FALSE   0       user_role       student
```

Рядок cookie має формат Netscape і містить сім полів:

| Поле | Значення для `session_key` | Опис |
|---|---|---|
| Домен | `httpbin.org` | Домен, для якого надсилається cookie |
| Прапорець subdomain | `FALSE` | Cookie не позначена як доступна для піддоменів |
| Шлях | `/` | Cookie доступна для всіх шляхів домену |
| Secure | `FALSE` | Cookie не обмежена лише HTTPS-запитами |
| Термін життя | `0` | Сесійна cookie, без заданого терміну дії |
| Ім'я | `session_key` | Назва cookie |
| Значення | `lab1_token` | Значення cookie |

Другий рядок має такі самі атрибути, але містить cookie `user_role=student`.

## 3. Повторна передача cookies

Збережені cookies передано до endpoint перевірки:

```bash
curl -b cookies.txt "https://httpbin.org/cookies"
```

Прапорець `-b cookies.txt` читає Cookie Jar і додає відповідні cookies до HTTP-запиту.

Відповідь сервера:

```json
{
	"cookies": {
		"session_key": "lab1_token",
		"user_role": "student"
	}
}
```

## Висновок

Життєвий цикл cookies успішно перевірено:

1. Сервер встановив `session_key` і `user_role`.
2. `curl` зберіг їх у `cookies.txt` у Netscape-форматі.
3. Повторний запит прочитав cookies із файлу та передав їх серверу.
4. `httpbin.org/cookies` розпізнав обидва значення у тілі відповіді.
