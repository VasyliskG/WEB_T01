# Рівень 2.2 — аналіз заголовків та статусів

## Завдання 2.1: Отримання заголовків ресурсу без тіла

**Команда:**
```bash
curl -I "https://dummyjson.com/products"
```

**Флаг `-I`:** надсилає метод `HEAD` і виводить виключно HTTP-заголовки без тіла.

**Результат:** `HTTP/2 200`

| Заголовок | Значення |
|-----------|----------|
| `date` | Fri, 11 Sep 2026 18:45:14 GMT |
| `content-type` | application/json; charset=utf-8 |
| `access-control-allow-credentials` | true |
| `etag` | W/"ac3a-Q0j5X7Zb/GG4CpZwhP3POutAwN4" |
| `strict-transport-security` | max-age=15552000; includeSubDomains |
| `cache-control` | no-store |
| `cf-cache-status` | HIT |
| `server` | cloudflare |

**Висновок:** сервер повернув заголовки без тіла; кеш активний (age: 42758), TLS обов'язковий (HSTS).

## Завдання 2.2: Перевірка статусів помилок

### 404 Not Found

**Команда:**
```bash
curl -i "https://httpbin.org/status/404"
```

**Флаг `-i`:** виводить заголовки + тіло.

**Результат:** `HTTP/2 404`

| Заголовок | Значення |
|-----------|----------|
| `date` | Fri, 11 Sep 2026 18:51:53 GMT |
| `content-type` | text/html; charset=utf-8 |
| `content-length` | 0 |
| `server` | gunicorn/19.9.0 |
| `access-control-allow-origin` | * |
| `access-control-allow-credentials` | true |

**Висновок:** сервер echo повернув статус `404` з пустим тілом; дозволив CORS (`*`).

### 500 Internal Server Error

**Команда:**
```bash
curl -i "https://httpbin.org/status/500"
```

**Результат:** `HTTP/2 500`

| Заголовок | Значення |
|-----------|----------|
| `date` | Fri, 11 Sep 2026 18:52:00 GMT |
| `content-type` | text/html; charset=utf-8 |
| `content-length` | 0 |
| `server` | gunicorn/19.9.0 |
| `access-control-allow-origin` | * |
| `access-control-allow-credentials` | true |

**Висновок:** сервер імітував помилку сервера; заголовки ідентичні до 404, відрізняється тільки статус-код.
