## Деталі форматування

### Принципи прийняті

1. **Markdown структура**
   - H1 для назви документа (`# `)
   - H2 для основних розділів (`## `)
   - H3 для підрозділів (`### `)
   - Горизонтальна лінія `---` між секціями

2. **Код і команди**
   - Bash команди в блоках з ````bash`
   - HTTP запити в блоках з ````http`
   - JSON у блоках з ````json`
   - HTTP заголовки та сирі виводи у ````text`

3. **Таблиці**
   - Вирівняння: текст ліворуч, числа праворуч
   - Заголовки з вирівнюванням
   - Макс 5–6 стовпців для читаємості

4. **Коментарі в HTTP файлах**
   - `### Завдання N:` — назва
   - `# Метод:` — HTTP метод
   - `# Очікуваний результат:` — статус код
   - `# Аналіз:` — що перевіряти

5. **Порядок розділів**
   - Команда → Флаг / Опис → Результат → Таблиця / JSON → Висновок
