## 1.1 TLS Handshake Аналіз (curl -v)

**Завдання:** Виконати запит з детальним виводом (`-v` флаг) для дослідження процесу встановлення защищеного з'єднання.

**Команда:**
```bash
curl -v https://dummyjson.com/products/1
```

Флаг `-v` (verbose) показує:
- `*` — технічна інформація та етапи TLS
- `>` — байти відправлені клієнтом (запит)
- `<` — байти отримані від сервера (відповідь)

### Очікуваний вихід та інтерпретація

```
* Trying 172.67.205.42:443...
* TCP_NODELAY set
* Connected to dummyjson.com (172.67.205.42) port 443 (#0)
```

**Етап 1: TCP з'єднання**
- IP адреса: `172.67.205.42` (у фактичному запуску також отримано IPv6-адреси Cloudflare)
- Порт: `443` (стандартний для HTTPS)
- Status: Connected ✅

```
* ALPN, offering h2
* ALPN, offering http/1.1
* TLSv1.3 (OUT), TLS handshake, Client hello (1):
```

**Етап 2: ClientHello**
- Протоколи: h2 (HTTP/2), http/1.1
- TLS версія: TLSv1.3
- Клієнт надсилає список підтримуваних алгоритмів

```
* TLSv1.3 (IN), TLS handshake, Server hello (2):
* TLSv1.3 (IN), TLS handshake, Encrypted Extensions (8):
* TLSv1.3 (IN), TLS handshake, Certificate (11):
```

**Етап 3: ServerHello + Certificate**
- Сервер обирає TLSv1.3
- Передає цифровий сертифікат X.509

```
* Server certificate:
*  subject: CN=dummyjson.com
*  start date: Aug  8 13:24:21 2026 GMT
*  expire date: Nov  6 14:24:16 2026 GMT
*  issuer: C=US; O=Google Trust Services; CN=WE1
*  SSL certificate verify ok.
```

**Перевірка сертифіката:**
- Subject CN: `dummyjson.com`
- Видавець: `Google Trust Services WE1`
- Дійсний період: 2026-08-08 — 2026-11-06
- Статус: ✅ Verified

```
* TLSv1.3 (IN), TLS handshake, Finished (20):
* TLSv1.3 (OUT), TLS change cipher spec (1):
* TLSv1.3 (OUT), TLS handshake, Finished (20):
* SSL connection using TLSv1.3 / TLS_AES_256_GCM_SHA384 / X25519MLKEM768
```

**Етап 4: Key Exchange + Cipher Suite**
- Алгоритм обміну ключами: ECDHE (Elliptic Curve Diffie-Hellman)
- Шифронабір: `TLS_AES_256_GCM_SHA384`
- Аутентифікація сертифіката: ECDSA
- Протокол: TLSv1.3 ✅

## 1.2 HTTP Redirect на HTTPS

**Завдання:** Порівняти поведінку HTTP vs HTTPS.

**Команда (незахищений протокол):**
```bash
curl -I http://dummyjson.com/products/1
```

**Очікуваний результат:**
```
HTTP/1.1 301 Moved Permanently
Location: https://dummyjson.com/products/1
Content-Length: 0
```

**Аналіз:**
- Статус: `301 Moved Permanently`
- Заголовок `Location:` вказує на HTTPS URL
- Браузер/клієнт автоматично перенаправляється

## Таблиця TLS Handshake

| Етап | Опис | Протокол | Статус |
|------|------|----------|--------|
| 1. TCP Connection | Встановлення з'єднання на порт 443 | TCP | ✅ Connected |
| 2. ClientHello | Клієнт надсилає список підтримуваних версій TLS | TLS 1.3 | Sent |
| 3. ServerHello | Сервер обирає TLS 1.3 | TLS 1.3 | Negotiated |
| 4. Certificate | Сервер передає сертифікат | X.509 | ✅ Verified |
| 5. Key Exchange | ECDHE узгодження сесійних ключів | ECDHE | Complete |
| 6. Finished | Обидві сторони мають спільні ключі | Symmetric | Ready |

## Ключові Компоненти

### Сертифікат
```
Subject: CN=dummyjson.com
Issuer: CloudFlare Inc ECC CA-3
Valid: 2024-2025
Key: ECDSA P-256
```

### Cipher Suite
```
TLSv1.3 / ECDHE-ECDSA-AES256-GCM-SHA384

Розбір:
- ECDHE: Еліптична крива для обміну ключами
- ECDSA: Цифровий підпис
- AES256: 256-бітне симетричне шифрування
- GCM: Режим автентифікованого шифрування
- SHA384: Хеширування для цілісності
```
