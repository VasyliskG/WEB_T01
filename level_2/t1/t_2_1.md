# Рівень 2.1 — базові GET і POST запити

## GET /users

**Команда:**

```bash
curl -X GET "https://dummyjson.com/users?limit=2&select=firstName,email"
```

**Результат:** `200 OK`. Отримано два користувачі; параметри `limit=2` і `select=firstName,email` застосовано.

```json
{
    "users": [
        {"id": 1, "firstName": "Emily", "email": "emily.johnson@x.dummyjson.com"},
        {"id": 2, "firstName": "Michael", "email": "michael.williams@x.dummyjson.com"}
    ],
    "total": 208,
    "skip": 0,
    "limit": 2
}
```

## POST /posts/add

**Правильна команда:**

```bash
curl -i -X POST "https://dummyjson.com/posts/add" \
    -H "Content-Type: application/json" \
    -d '{"title":"Test Post Title","userId":1}'
```

**Фактичний результат першого запуску:** `400 Bad Request`, повідомлення `User id is required`. Причина — у збереженій команді був заголовок `" Content-Type: application/json"` із початковим пробілом, тому сервер не розпізнав `Content-Type` і не обробив тіло як JSON.

Після виправлення заголовка очікується `201 Created` з JSON-об'єктом нового посту. Повторний запуск слід виконати перед здачею, щоб додати фактичну відповідь до звіту.
